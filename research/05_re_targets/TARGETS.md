# Verso RE-TARGET LIST — Single Prioritized Source of Truth

**Compiled:** 2026-06-05 · **Consolidates:** all 12 category files in `research/05_re_targets/`
**Verso anchor:** Python async ReAct agent framework. Five core pillars decide the list:
(1) the tactical↔durable seam (`durable=True`, no rewrite), (2) typed/scoped/pluggable memory,
(3) first-class evals + native trace schema, (4) `@tool` / structured-output / schema compilation,
(5) the peer frameworks Verso is positioned against.

**How priority was assigned (ruthless):**
- **P0** = shapes a Verso CORE decision you cannot un-make later: the durable-execution mechanics,
  the memory data model, the eval/trace schema, structured-output/schema compilation, the embedded↔distributed
  storage seam, or a peer framework Verso is directly positioned against. If RE'ing it changes the
  shape of a Verso primitive's API, it is P0.
- **P1** = strong reference that shapes ONE subsystem (a load-balancer algorithm, a context-narrowing
  pattern, a sandbox adapter, a metric implementation) but does not move the core API.
- **P2** = useful calibration / survey / negative-space / closed-with-thin-surface. Read if time allows.

Category P0/P1 ratings from the source files were **demoted on consolidation** where the target shapes
a subsystem but not a core seam (e.g. most gateways, most coding agents, most vector stores moved P0→P1).
A category-local "P0" is not automatically a global P0.
